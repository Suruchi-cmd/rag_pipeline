The April Birthday Promotion is currently active. To take advantage of this promotion, you must book by April thirty-first and host the event by September thirtieth. The promotion offers discounts on different types of parties. For a Premium Party, there is a discount of fifty dollars off with the promo code AprilBDAY50. A VIP Party comes with a discount of one hundred dollars off using the promo code AprilBDAY100. Lastly, an Ultimate Party can be discounted by one hundred and fifty dollars off with the promo code AprilBDAY150.
